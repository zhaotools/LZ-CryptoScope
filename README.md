# LZ CryptoScope · 加密基本面观察

一个公开、静态的加密项目研究站。页面包含三个动态 Top 10、48 个项目资料、每日官方来源新闻简报，以及用户提供的 2026-09-28 历史三榜。

## 本地运行

需要 Node.js 22 或以上。项目没有 npm 依赖。

```bash
node scripts/update-market.mjs
node scripts/update-news.mjs
node scripts/check.mjs
python3 -m http.server 8765
```

打开 `http://localhost:8765/`。不要直接用 `file://` 打开 `index.html`，因为页面通过 `fetch` 读取 JSON。

## 每日更新

- GitHub Actions `market.yml` 每天北京时间 09:45 运行，取前一日已完成的 UTC 日线，重算近 30 天、近 90 天、年初至今的 Top 10，提交 `data/daily.json`。
- `news.yml` 每天北京时间 20:15 检查已接入官方来源，发布一份按北京时间归档的简报，提交 `data/news.json`。没有合格新闻时也会发布空简报；部分来源失败时显示覆盖数。
- 两个工作流都支持手动触发。GitHub 计划任务可能延迟；网页依据快照时间显示延迟，不将旧数据伪装成实时数据。
- 更新脚本先验证关键数据覆盖，再原子替换快照。市场数据不完整时，保留上一份已发布结果。

## 统计范围与计算

研究候选池在 `data/universe.mjs`，需人工审查变更。它是一个公开名单，不声称覆盖所有加密货币。当前排除 BTC、ETH、稳定币、锚定资产及纯 Meme 项目；BTC 和 ETH 仅作曲线基准。

收益使用 Binance Spot `*USDT` 交易对的 UTC 完整日收盘价，公式为 `(终点收盘价 / 起点收盘价 - 1) × 100`。近 30/90 天以结束日前 30/90 个完整 UTC 日的收盘价为基准；YTD 以上年 12 月 31 日的收盘价为基准。缺任一基准日价格则该项目不参与对应周期排名；图表与榜单读取同一数据快照。

## 数据来源

| 数据 | 来源 | 页面显示边界 |
| --- | --- | --- |
| 榜单、曲线、现货 24h 成交额 | Binance Spot 公共行情 | 排行使用 USDT 交易对日收盘；成交额仅为该交易所现货交易对 |
| 当前市值、价格、供应量 | CoinLore API | 与榜单收盘时间不同；完全稀释估值按价格与最大供应量计算 |
| 合约持仓、资金费率与成交额 | Hyperliquid Perps 公共行情 | 仅覆盖其已上线的永续合约市场；持仓价值按标记价估算，资金费率为当前每小时费率；不可用显示“—” |
| TVL、费用、协议收入 | DefiLlama API | 仅显示在候选池中逐项指定的子协议；不同概念分别列示 |
| 每日新闻 | `data/news-sources.mjs` 内的项目官方论坛及 GitHub Releases | 只保存标题、日期、项目、分类和原始链接；不复制文章正文 |

新闻筛选是自动规则，不等同人工事实核查，也不覆盖整个市场。历史新闻若缺原始链接或日期，不会被猜测补录。

## 发布

仓库适合以 GitHub Pages 的 `main` 分支根目录发布。仓库与网页都应设置为公开。发布后分别检查：本地页面、GitHub 提交、Pages 构建状态、线上 HTML 和 JSON 数据日期。
